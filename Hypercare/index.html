First run

This tool ships without any data

It is an empty analyser. Everything it shows — which pilots exist, who is on each roster, which controls are being validated, and every row of activity — comes from one file that your team supplies. Nothing is bundled with the page and nothing is sent anywhere: what you load stays in this browser.

Load a snapshot to start

A snapshot carries the configuration and the accumulated rows together, so a single file is all you need. A configuration on its own works too, if you are starting with no data yet — the same button takes either.
